# python3의 hashlib함수를 사용하여 다양한 실험을 해봄
<code>hashing</code>은 파이썬의 hash함수를 사용하여 hash의 원리와 간단한 무작정 대입 알고리즘을 제작
<code>block_chain</code>은 파이썬의 hash함수를 응용하여 개인 학습 목적의 간단한 블록체인을 제작
# 블록체인 실행 시키는 방법
<code>pip install -r requirements.txt</code>
</br>
<code>python3 /block_chain/server.py</code>
